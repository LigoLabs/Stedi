#  ARRIVEES SUR LA PLATEFORME

#  12 combinaisons possibles : CHAQUE arrivee finit exactement sur REPOS, qui est aussi
#  l'image 1 de chaque pose. Le raccord est donc exact quel que soit le couple choisi.
#
#  Le deplacement d'ensemble (le perso qui traverse, saute, tombe) est porte par un objet

#  tables ci-dessous restent donc ecrites dans le repere du personnage, comme les poses.
#
#  Le cadre des arrivees est LARGE (sensor_fit vertical) pour que la course entre depuis
#  hors champ sans changer le cadrage vertical : le perso garde exactement la meme taille
#  et la meme ligne de pieds que dans les poses, ce qui est indispensable au raccord.
# ==========================================================================
